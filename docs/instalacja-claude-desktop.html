Skille prawnicze w aplikacji Claude Desktop

Jak zainstalować otwarte skille prawnicze z repozytorium jamarpl21/prawo-pl-eli w aplikacji desktopowej Claude (Mac/Windows). Główna metoda: wklejenie adresu repozytorium — bez pobierania i pakowania czegokolwiek. Wszystkie sześć skilli instaluje się w ~2 minuty. Na końcu: te same skille w Claude Code (część C) i w aplikacji ChatGPT Desktop (część D).

prawo-pl-eli prawo-pl-edzienniki prawo-eu-eurlex prawo-pl-saos prawo-pl-cbosa prawo-pl-uodo

Część A — instalacja przez URL (zalecana)

Repozytorium jest gotowym marketplace'em pluginów — aplikacja pobierze z niego skille sama. Nie ściągasz plików, nie pakujesz ZIP-ów.

1

Włącz wykonywanie kodu

Skille wymagają aktywnej funkcji wykonywania kodu. Otwórz Settings→Capabilities i włącz Code execution. W planach Team/Enterprise tę funkcję musi najpierw włączyć administrator organizacji.

Settings → Capabilities
Code execution Pozwala Claude uruchamiać kod — wymagane przez skille
2

Dodaj repozytorium jako plugin

Otwórz Settings→Customize→Plugins, kliknij + Add plugin i wklej adres repozytorium — wystarczy krótka forma:

jamarpl21/prawo-pl-eli
# zadziała też pełny adres:
# https://github.com/jamarpl21/prawo-pl-eli

Zatwierdź przyciskiem Sync — aplikacja wczyta katalog marketplace'u gibek-skills.

Settings → Customize → Plugins → Add plugin
jamarpl21/prawo-pl-eli Sync
3

Wybierz skille i zainstaluj

Z wczytanego katalogu wybierz pluginy, które chcesz mieć, i kliknij Install przy każdym. Możesz zainstalować wszystkie sześć albo tylko te potrzebne — np. samo prawo-pl-eli (ustawy) i prawo-pl-saos (orzecznictwo).

gibek-skills · 6 pluginów
prawo-pl-eli Polskie akty prawne z API ELI Sejmu (Dz.U./M.P.) ✓ Installed
prawo-pl-saos Orzecznictwo: SN, TK, sądy powszechne, KIO (API SAOS) ✓ Installed
prawo-pl-cbosa Orzecznictwo sądów administracyjnych: NSA i 16 WSA Install
Włącz auto-aktualizacje marketplace'u, a nowe wersje skilli będą pobierane same.
4

Przetestuj — skill uruchomi się sam

Skilli nie wywołuje się ręcznie: Claude sam sięga po właściwy, gdy pytanie pasuje do jego opisu. Zadaj pytanie testowe i sprawdź, czy w odpowiedzi pojawia się informacja o użyciu skilla.

Nowa rozmowa
Znajdź aktualne orzeczenia SN o zadośćuczynieniu za naruszenie dóbr osobistych
⚙ Używam skilla prawo-pl-saos
Przeszukałem bazę SAOS. Najnowsze orzeczenia Sądu Najwyższego w tej materii to…
Ograniczenie: dostęp do internetu

Skille z tego repozytorium odpytują publiczne API (Sejm, SAOS, EUR-Lex…). W zwykłym czacie Claude wykonuje kod w piaskownicy, która może nie mieć dostępu do tych serwerów — wtedy skill się załaduje, ale nie pobierze danych. Pełną funkcjonalność dają Cowork (wykonywanie na Twoim komputerze) oraz Claude Code (część C poniżej).

Część B — wariant ZIP (pojedynczy skill lub własna kopia)

Alternatywa, gdy chcesz wgrać jeden skill ręcznie albo zmodyfikowaną własną kopię. Trzy kroki:

1

Pobierz repozytorium

Na github.com/jamarpl21/prawo-pl-eli kliknij Code→Download ZIP i rozpakuj. Każdy skill to folder w plugins/<nazwa>/skills/<nazwa>/ z plikiem SKILL.md w środku.

2

Spakuj skill do ZIP — folder w środku, nie same pliki

Najczęstszy błąd: ZIP musi zawierać folder skilla, a nie luźne pliki. Zaznacz cały folder (np. prawo-pl-saos) i dopiero jego spakuj.

✓ Dobrze
prawo-pl-saos.zip
└─ prawo-pl-saos/
   ├─ SKILL.md
   ├─ scripts/
   └─ references/
✗ Źle — instalacja się nie uda
prawo-pl-saos.zip
├─ SKILL.md ← pliki luzem
├─ scripts/
└─ references/ 
# macOS/Linux — z katalogu repozytorium:
cd plugins/prawo-pl-saos/skills
zip -r prawo-pl-saos.zip prawo-pl-saos
3

Wgraj ZIP w ustawieniach

Settings→Customize→Skills→+→Upload a skill, wskaż ZIP i po wgraniu upewnij się, że przełącznik przy skillu jest włączony. Uwaga: tak wgrany skill nie aktualizuje się sam — po nowej wersji w repozytorium usuń go i wgraj świeży ZIP.

Część C — Claude Code (aplikacja desktopowa i terminal)

W Claude Code repozytorium podłącza się tym samym adresem, poleceniami w oknie rozmowy:

# 1. Dodaj marketplace (jednorazowo):
/plugin marketplace add jamarpl21/prawo-pl-eli

# 2. Zainstaluj wybrane skille:
/plugin install prawo-pl-eli@gibek-skills
/plugin install prawo-pl-edzienniki@gibek-skills
/plugin install prawo-eu-eurlex@gibek-skills
/plugin install prawo-pl-saos@gibek-skills
/plugin install prawo-pl-cbosa@gibek-skills
/plugin install prawo-pl-uodo@gibek-skills

# Aktualizacje w przyszłości:
/plugin marketplace update

Zamiast poleceń możesz też wpisać samo /plugin — otworzy się menedżer z zakładkami Discover, Installed i Marketplaces, w którym wszystko wyklikasz.

Część D — aplikacja ChatGPT Desktop (tryby Work i Codex)

Skille działają też w zunifikowanej aplikacji ChatGPT (Mac/Windows, od 9 lipca 2026, z wbudowanym Codexem) — są w otwartym standardzie Agent Skills, wspólnym dla obu ekosystemów.

1

Dodaj marketplace przez CLI Codexa

W terminalu (jednorazowo):

codex plugin marketplace add jamarpl21/prawo-pl-eli
codex plugin add prawo-pl-eli@gibek-skills
# analogicznie pozostałe: prawo-pl-edzienniki, prawo-eu-eurlex,
# prawo-pl-saos, prawo-pl-cbosa, prawo-pl-uodo
2

Znajdź pluginy w aplikacji

W aplikacji ChatGPT przełącz się na tryb Work albo Codex i otwórz panel Plugins. Pluginy zainstalowane przez CLI znajdziesz w zakładce Personal.

ChatGPT → Codex → Plugins → Personal
prawo-pl-eli gibek-skills · Polskie akty prawne z API ELI Sejmu ✓ Installed
prawo-pl-saos gibek-skills · Orzecznictwo: SN, TK, sądy powszechne, KIO ✓ Installed
3

Zacznij nową sesję

Skille z pluginów stają się aktywne dopiero w nowej sesji — rozpocznij nową rozmowę/zadanie i zadaj pytanie testowe, jak w części A.

Rozwiązywanie problemów

ObjawPrzyczyna i rozwiązanie
Sync nie znajduje pluginów Sprawdź adres — poprawna forma to jamarpl21/prawo-pl-eli (bez dodatkowych ścieżek). Repozytorium musi być dostępne publicznie — jest.
Nie widać sekcji Skills/Plugins Wykonywanie kodu jest wyłączone (część A, krok 1) albo — w Team/Enterprise — administrator nie włączył skilli dla organizacji.
Błąd przy wgrywaniu ZIP W archiwum są luźne pliki zamiast folderu skilla — spakuj ponownie wg części B, krok 2.
Skill się nie uruchamia Sprawdź, czy plugin/skill jest włączony w Customize. Zadaj pytanie bliżej tematu skilla (np. z sygnaturą orzeczenia lub nazwą ustawy) — Claude dobiera skill po jego opisie.
Skill działa, ale nie pobiera danych Piaskownica czatu nie ma dostępu do API — użyj Cowork albo Claude Code (ramka w części A).
ChatGPT: plugin widać, skille nieaktywne Skille z pluginów ładują się dopiero w nowej sesji — zamknij bieżącą rozmowę i zacznij nową (część D, krok 3).
